# kurocafe ローカルサイト

このフォルダがサイトの実装です。共通ルールと案件方針は親フォルダの文書を参照してください。

## 起動

このフォルダで `npm install`（初回のみ）、続けて `npm run dev` を実行します。
表示URLは開発サーバーに表示されます。通常は http://localhost:3000/ です。

## 確認

- `npm run build` : 本番用のビルド確認
- `npm exec tsc -- --noEmit` : 型検査
- `npm run lint` : 静的解析

## 編集場所

- `app/page.tsx` : ページ構成・文章・ナビゲーション・FAQ・相談テンプレート
- `app/globals.css` : 色・レイアウト・スマートフォン向けの表示
- `app/layout.tsx` : タイトル・説明文・日本語設定
- `public/assets` : 表示用素材

現在はクライアント確認用の初版です。Vercelへ配信できるNext.js構成です。検索エンジンへの登録は抑止しています。

## 正式情報への差し替え

- オーナーの想いは、了承済みのダミー原稿です。ヒアリング後に差し替え、仮原稿の表示を外します。
- 価格・サイズ・原材料・アレルギー情報は未確認です。
- 車両写真・接客風景・実績は未取得のため、実在する情報として掲載していません。
- 出店条件と相談の流れはオーナーに最終確認が必要です。
- 出店相談は既存Instagramプロフィールを開く導線です。フォーム送信や自動メッセージ送信はありません。
- スケジュールはInstagramの最新情報へ誘導し、古い出店予定を固定表示しません。
- 公開前に正式画像・原稿、運営情報、条件、相談先を確定してください。

## 素材

`public/assets/stickers-original.jpg` は、許可済みのInstagram投稿から取得した画像です。
参照元: https://www.instagram.com/kurocafe96/p/DW29frXjzuY/
画像そのものを描き直さず、CSSの表示範囲で左上の丸型ロゴを使用しています。正式な単体ロゴ入手後に置換可能です。

`public/assets/jungle-hero.png` は承認済みFV案を参照して、内蔵画像生成ツールで制作した仮ビジュアルです。
商品写真および大きなキャラクターは実物の写真・正式な原画ではありません。
生成指示: 承認済みFV案の右側を参考に、バナナの皮を頭に乗せた親しみやすい灰色のゴリラ、手前に紙トレーのベビーカステラと透明カップのばななスムージー、奥と右に青緑・深緑の葉。クリーム背景、4:5の構図。文字・ロゴ・UIを含めず、独立したサイト用ビジュアルにする。

## 初版の確認記録

ローカルHTTP応答、両画像の配信、セクションリンクの宛先、日本語メタデータ、ダミー版のnoindexを確認済み。
全体の静的解析は、スターター同梱の未使用UI部品・フックに既存の指摘が残っています。サイト用の作成部分と使用中のアコーディオンは別途検査しています。ブラウザ操作による実機・画面幅ごとの表示検証は未実施です。
